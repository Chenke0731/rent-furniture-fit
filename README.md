# 租房家具适配本（rent-furniture-fit）

面向青年租房群体的多约束家具适配与可解释决策小程序 / H5 原型（基于 `uni-app` + Vue 3 + TypeScript）。

## 核心功能

- **第 1 步 · 量角落（租房档案）**：录入放置位置可用宽度、纵深、限高、前方留空、最窄门宽、打孔限制、预计租期与预算，提供现场测量方法提示。
- **第 2 步 · 挑候选家具**：支持书桌、置物架、小型收纳柜筛选（勾选 2—5 款对比），支持按商品详情页手动贴入商品（未披露字段留空即可）。
- **第 3 步 · 适配审核单（两阶段可解释决策）**：
  - **第一阶段（硬约束核验）**：按 `冲突` > `信息不足` > `有条件适配` > `适配` 优先级逐项检验并给出具体差值或买前待确认项；缺少关键尺寸时输出“信息不足”，不因低价判为适配。
  - **第二阶段（偏好比较排序）**：仅对通过硬约束的商品按总成本、拆装搬迁便利度、同类功能大小加权排序。
- **实验模式**：按参与者编号自动分入 4 个顺序平衡组（平衡条件 A 普通参数列表 / 条件 B 适配审核单 及任务 T1/T2 顺序），自动记录决策用时、所选商品冲突状态、展开次数与主观评分，支持一键导出 CSV。

## 本地运行与构建

```bash
# 安装依赖
npm install

# 启动 H5 网页预览
npm run dev:h5

# 运行规则引擎单元测试（Vitest）
npm test

# TypeScript 类型检查
npm run type-check

# 构建微信小程序包（产物位于 dist/build/mp-weixin）
npm run build:mp-weixin
```

## 批量导入人工核验商品库（CSV）

数据组按 `data-template.csv` 表头填写核验后的商品参数（未知项留空），运行以下命令即可校验并替换 `src/data/sample.ts`：

```bash
node scripts/import-csv.mjs data-template.csv --write
```
